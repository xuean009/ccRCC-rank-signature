# Data Layout

This repository does not ship raw public datasets. Place downloaded files in the following locations before running the scripts.

## Bulk transcriptome data

- `data/TCGA_Xena/`
  - Created by `scripts/01_download_tcga_xena.R`
  - Expected downstream files:
    - `data/TCGA_Xena/TCGA.KIRC.sampleMap/HiSeqV2.gz`
    - `data/TCGA_Xena/TCGA.KIRC.sampleMap/KIRC_clinicalMatrix`

- `data/GEO/GSE29609_series_matrix.txt.gz`
  - GEO series matrix for GSE29609
  - Source: <https://ftp.ncbi.nlm.nih.gov/geo/series/GSE29nnn/GSE29609/matrix/GSE29609_series_matrix.txt.gz>

- `data/GEO/annot/GPL1708.annot.gz`
  - GPL1708 platform annotation for GSE29609
  - Source: <https://ftp.ncbi.nlm.nih.gov/geo/platforms/GPL1nnn/GPL1708/annot/GPL1708.annot.gz>

- `data/gene_lists/common_topvar_1500.tsv`
  - Generated by `scripts/03_build_common_gene_list.R`

- `data/cBioPortal/rcc_cptac_gdc/sample_to_patient.tsv`
  - Generated by `scripts/02_download_cptac_cbioportal.py`

- `data/cBioPortal/rcc_cptac_gdc/expr_genelist.tsv`
  - Generated by `scripts/04_fetch_cptac_expression.py`

- `data/cBioPortal/rcc_cptac_gdc/clinical_os_gdc.tsv`
  - Generated by `scripts/05_download_cptac_gdc_clinical.py`

- `data/external_clinical/`
  - Manually recovered supplementary clinical follow-up tables for public external cohorts
  - Current contents:
    - `data/external_clinical/E-MTAB-1980/clinical_matched_101.tsv`
    - `data/external_clinical/E-MTAB-3267/clinical_matched_53.tsv`
    - `data/external_clinical/IMmotion150/clinical_matched_263.tsv`
    - `data/external_clinical/Choueiri2016/clinical_matched_16.tsv`
    - notes and source files for `GSE73731`, `E-MTAB-1980`, `E-MTAB-3267`, `ICGC_RECA-EU`, `IMmotion150`, and `Choueiri2016`

## Single-cell RNA-seq

- `data/scRNA/GSE159115/GSE159115_RAW.tar`
- `data/scRNA/GSE159115/GSE159115_ccRCC_anno.csv.gz`

These files are downloaded automatically by `scripts/07_plot_scrna_signature.R` if missing.

## Spatial transcriptomics

- `data/spatial/GSE250163/GSE250163_RAW.tar`

This file is downloaded automatically by `scripts/08_plot_spatial_signature.R` if missing.
